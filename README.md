# Полина · NARRA STUDIO — сайт-визитка

Кинематографичный сайт из трёх сцен: «Обо мне», «Кейсы», «Контакты» (+ страница каждого кейса).

## Запуск

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # статическая сборка в dist/ — можно залить на любой хостинг
```

Нужен Node 22+.

## Стек

- **Astro** — статический сайт без лишнего JS, отдельная HTML-страница на каждый раздел, хорошо для SEO и быстрой загрузки.
- **GSAP + ScrollTrigger + SplitText** — горизонтальная плёнка, закреплённые сцены, титры по буквам.
- **Lenis** — плавная инерционная прокрутка.
- Шрифты (self-hosted через Fontsource, с кириллицей): Oranienbaum — титры, Onest — текст, Martian Mono — маркировка плёнки и таймкод.

## Где что менять

| Что | Файл |
|---|---|
| Имя, девиз, Instagram, Telegram, почта | `src/data/site.ts` |
| Кейсы: названия, тексты, фото, видео | `src/data/cases.ts` |
| Видео для фонов (главная, контакты) | `src/data/media.ts` |
| Цвета, шрифты, общие элементы | `src/styles/global.css` |

Сейчас все видео и фото — бесплатные стоковые файлы Pexels, подгружаются с их CDN.
Для боевой версии положите свои файлы в `public/media/` и укажите пути вида `/media/dien.mp4`.
Видео для фона лучше готовить в 720p, 5–15 секунд, без звука, H.264 — до 3–5 МБ на ролик.

## Что внутри

- **Раккорд 3-2-1** при первом заходе за сессию (клик — пропустить).
- **Шторка-хлопушка** между страницами: название следующей сцены.
- **Таймкод** в шапке считает, сколько «фильма» вы прокрутили.
- **Главная:** каше 2.39:1, которое раскрывается при скролле; синопсис проявляется по словам; три акта (смысл → структура → ясность) сменяют друг друга в одном кадре; услуги с превью-роликом у курсора; две плёнки едут навстречу.
- **Кейсы:** вертикальный скролл тянет 35-мм плёнку справа налево, активный кадр «в окне проектора» подсвечивает фон, по таймлайну можно перематывать.
- **Страница кейса:** раскадровка едет в обратную сторону — слева направо.
- **Контакты:** пустой зал, финальные титры, кнопки связи.
- Учитывается `prefers-reduced-motion`: без анимаций плёнка листается обычным горизонтальным скроллом, видео показываются постерами.
